      Staden byggs av dina riktiga repon. Token sparas bara i den här telefonen och behöver bara läsrätt.

      Så skapar du en token
      1. Öppna Fine-grained token på GitHub.
      2. Namn: Commit-staden. Expiration: till exempel 1 år.
      3. Repository access: All repositories.
      4. Permissions › Repository: sätt Actions, Contents, Issues och Pull requests till Read-only. Metadata blir Read-only av sig själv.
      5. Tryck Generate token, kopiera och klistra in här.
